# Monitor de Actividad del Sistema
- Debe generar reportes para la detección temprana de anomalías internas.
- Se requiere un script que registre uso de CPU, memoria y procesos.

![Captura 1: Menu principal](./assets/capturas_ejecutable/snapsys_mainmenu.png)

## Especificaciones:
- Lenguaje principal: Python.

## Cómo hacer uso del sistema.
### Ejecutable:
  Al entrar a la carpeta se encontrará un archivo llamado `index.exe`, el cuál es un eecutable funcional en el sistema operativo Windows.
  Para hacer uso de él, solo se debe dar doble click derecho y se ejecutará una ventana de Powershell con el programa.
### Terminal:
Requisitos:
* Tener Python instalado.
Pasos:
1. Abrir una terminal y ubicarse en la ruta `\monitorsistema.python_traductoreseinterpretes\src`.
2. Colocar el comando `py index.py` o `python index.py` y presionar `Enter`.
3. Para salir del programa presionar: `Ctrl` + `C`.
Extra: Para limpiar la temrinal colocar el comando `clear`.
